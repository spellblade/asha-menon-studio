# ADR-0001: Record architecture decisions

## Status

Accepted

## Context

This repo is a personal CV that other people may fork. Irreversible choices (database, editor gate, host) should be written down so a future change is deliberate.

## Decision

Keep short ADRs in `docs/adr/`, numbered, with Status / Context / Decision / Consequences.

## Consequences

- Positive: GitHub visitors see why Studio is not OAuth.
- Negative: One extra folder to keep in sync with code.
